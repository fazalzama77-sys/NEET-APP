# NEET-UG Clinical Revision & Exam Trainer 🩺⚡

> **Official NMC 2026 NEET (UG) Syllabus — Full 40-Unit Interactive Revision & Spaced Repetition Exam Trainer**
> Standalone, single-file clinical web application designed for rapid pictographic memory encoding, active blind recall, and high-yield trap elimination.

🌐 **Live GitHub Pages Web App:** [https://fazalzama77-sys.github.io/NEET-APP/](https://fazalzama77-sys.github.io/NEET-APP/)

---

## 🎯 Architecture & Philosophy
Built for NEET-UG aspirants aiming for AIR < 5000:
- **Zero Gamification Bloat:** No coins, avatars, XP bars, or distractions. Clean, high-contrast Clinical Light Medical Theme by default (plus optional Dark Mode).
- **Interactive 4-to-5 Page Short-Notes Replacement:** Every chapter is bounded to maximum 4 pages (5 pages for high-weightage chapters) with interactive numerical sandboxes, order scrambles, step-by-step reaction walks, and NCERT truth spotters.
- **Active Blind-Recall Switch:** Toggle to blur all formulas, exception causes, and reagents to enforce active neural retrieval instead of passive reading.
- **Cognitive Reflex Drill & 3-Round Strategy:** Generates 20 high-yield questions for Physics/Physical Chemistry units and 30 questions for Inorganic/Organic units with an anti-panic 60s pace bar, "Mark for Round 2 & Skip" workflow, and an automatic Mistake Vault.
- **Mock Syllabus Lock & Spaced Repetition (SRS):** 1-Click 40-unit matrix + smart regex parser to paste test schedules from Allen/Aakash/PW and auto-schedule spaced review intervals.

## 🛠️ How to Run Locally

Because the entire application is standalone and self-contained in `index.html`:
```bash
# 1. Clone the repository
git clone https://github.com/fazalzama77-sys/NEET-APP.git

# 2. Open index.html directly in your browser
cd NEET-APP
start index.html   # On Windows
open index.html    # On macOS
xdg-open index.html # On Linux
```
No Node.js, Python, or local server is required to use the app.

## 📦 Build Pipeline
